# 文体

文体（`Style`）は、節がどう書かれているか。節全体の言葉遣い（`Diction`）と、文の並び（`Sentences`、文ごとの組み立て `Construction` の並び）を束ねたもの。言葉遣いは節全体で見るので一つにし、組み立ては文ごとに違うので文の数だけ持つ。文体そのものは性質を持たず、性質はそれぞれ言葉遣いと文の組み立ての側に置く。

二つに分けるのは、読者の別々の負担につなぐためである。言葉遣いは、読者の語彙と照らして知らない語を調べる負担に、文の組み立ては、文を頭に保持する負担（文の長さなど）につなぐ。どちらもまだ読者の費用にはつないでいない。

## 言葉遣いの性質

言葉遣いからは、使っている語と、新しく導入する語を取り出せる。

| 性質 | 意味 |
| --- | --- |
| 具体的（`Diction.Concrete`） | 例・数値・固有の事柄で書く |
| 新しい語を導入しない（`Diction.NoNewWords`） | それまでに出てきた言葉だけで書く。結論や判断を求める節で、読者が大事なところで立ち止まらないようにする |
| 言い直さない（`Diction.NoRephrasing`） | 同じ概念を指す語は同じ語にする。節をまたいで起こるので、言葉遣いの並びについての条件にする |

未知の語を、読者が知っている言葉による説明に置き換えると、語を調べる負担は減るが、読む時間は増える。語を知っている読者にはかえって遠くなるので、どちらがよいかは読者で決まる。

## 文の組み立ての性質

組み立ては文ごとなので、節の性質は、文の並びについて「どの文も」か「ある文が」で書く。

| 性質 | 意味 |
| --- | --- |
| 言い切る（`Sentences.Assertive`） | どの文も、留保なしに断定する |
| つながりを示す（`Sentences.Connective`） | 前の節とどう関係するか（理由・帰結など）を明示する文がある |
| 依頼する（`Sentences.Requesting`） | 読者にしてほしい判断や行動を、はっきり求める文がある |
| はい／いいえで答えられる（`Sentences.YesNo`） | 依頼する文はどれも、はい／いいえで答えられる。何を答えればよいか分からない依頼を防ぐ |

これらの性質の中身はまだ定めておらず、名前と意味だけを置いている。役割が節ごとに取るべき文体を、文書の種類が節をまたいで取るべき文体を定めるのに使う（[文書の種類](../Genre/genre.md)）。
