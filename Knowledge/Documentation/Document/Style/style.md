# 文体

文体（[`Style`](./Model.lean)）は、各節がどう書かれているか。どう並べるか（レイアウト）とは別に、各節が持つ。言葉遣い（[`Diction`](./Model.lean)）と文の組み立て（[`Construction`](./Model.lean)）からなる。

## 言葉遣いの性質

言葉遣いからは、使っている語と、新しく導入する語を取り出せる。

| 性質                                                         | 意味                                                                                                   |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| 具体的（[`Style.Concrete`](./Diction.lean)）                 | 例・数値・固有の事柄で書く                                                                             |
| 新しい語を導入しない（[`Style.NoNewWords`](./Diction.lean)） | それまでに出てきた言葉だけで書く。結論や判断を求める節で、読者が大事なところで立ち止まらないようにする |
| 言い直さない（[`Style.NoRephrasing`](./Diction.lean)）       | 同じ概念を指す語は同じ語にする。節をまたいで起こるので、文体の並びについての条件にする                 |

未知の語を、読者が知っている言葉による説明に置き換えると、語を調べる負担は減るが、読む時間は増える。語を知っている読者にはかえって遠くなるので、どちらがよいかは読者で決まる。

## 文の組み立ての性質

| 性質                                                             | 意味                                               |
| ---------------------------------------------------------------- | -------------------------------------------------- |
| 言い切る（[`Style.Assertive`](./Construction.lean)）             | 結論を、留保なしに断定する                         |
| つながりを示す（[`Style.Connective`](./Construction.lean)）      | 前の節とどう関係するか（理由・帰結など）を明示する |
| 依頼する（[`Style.Requesting`](./Construction.lean)）            | 読者にしてほしい判断や行動を、はっきり求める       |
| はい／いいえで答えられる（[`Style.YesNo`](./Construction.lean)） | 何を答えればよいか分からない依頼を防ぐ             |

これらの性質の中身はまだ定めておらず、名前と意味だけを置いている。文書の種類が、節の役割ごとに取るべき文体を定めるのに使う（[文書の種類](../Genre/genre.md)）。
