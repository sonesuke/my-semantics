# Documentation

文章の知識。文書は、内容を、種類に従って、節の並びにしたもの、という形で説明する。内容は事柄と話題（読む人の問い）からなり、節は役割（読む人に対する働き）と事柄と文体を持つ。種類は節の並べ方と、内容を節にする方針を決め、読者はその種類に期待して読む。

- [文書](./Document/document.md) — 内容と話題・役割・節・文書の種類に従うこと
- [文体](./Document/Style/style.md) — 言葉遣いと文の組み立て
- [文書の種類](./Document/Genre/genre.md) — 並べ方・節をまたいだ文体・内容を節にする方針。提案書・PREP 法
- [読者](./Reader/reader.md) — 読む過程、理解までの距離、種類への期待、目的が求める話題
