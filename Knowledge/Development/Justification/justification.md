# 理由

理由（[`Justification`](./Model.lean)）は、何かがなぜ妥当かを述べるもので、受け入れるかどうかは人間の承認で判断する。中身は定めず、どこで何を述べるかだけを決める。

| 置かれる場所     | 述べること                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------ |
| Issue の変更要件 | なぜその変更を求めるか（要求の価値）。これが PR の既定路線を定める                         |
| PR               | 既定路線との差がなぜ妥当か（範囲を変えた理由、確かめない部分の理由、見積もりを超えた理由） |

Issue の理由は、差を正当化するものではない。要求を足せば費用は増えるが、それは価値と引き換えに払うものだからである。差を正当化するのは PR の理由だけで、その差の数だけ承認する人が読む理由が増え、承認の費用が上がる（[費用](../Cost/cost.md)）。
