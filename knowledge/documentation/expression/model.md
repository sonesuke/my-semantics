# 文章の読みやすさのモデル

喉越しのよい表現は、読者の知識・語彙を足場に、目的に必要な理解へ少ない負担で進める表現である。理解は、読後に説明・判断・実行できることとして評価する。

平易さは、読者と表現の関係で決まる。専門家には専門用語が近く、初心者には具体的な動作や身近な例が近いことがある。

## 評価の前提

\[
\mathcal M=(\Omega,\Gamma,C,G,K_0,\mathcal O,\mathcal E)
\]

| 記号                                | 定義                                       |
| ----------------------------------- | ------------------------------------------ |
| \(\Omega\)                          | 説明対象について考えられる状況の集合       |
| \(\Gamma\subseteq\Omega\)           | 共有する前提に適合する状況の集合           |
| \(\varnothing\ne C\subseteq\Gamma\) | 伝える内容に適合する状況の集合             |
| \(G\)                               | 読者の目的を表す、有限で空でない課題の集合 |
| \(K_0\)                             | 読む前の読者の状態                         |
| \(\mathcal O\)                      | 許す操作とその遷移関係                     |
| \(\mathcal E\)                      | 媒体、制限時間、外部資料などの閲覧条件     |

読者の状態を \(K=(V,H,A)\) とする。\(V\) は語と概念の対応、\(H\) は保持する命題や事例、\(A\) は説明・判断・実行の能力である。誤解を含む状態も扱う。

表現 \(e\) には、言葉遣い、文の組み立て、説明の順序、具体例、図表、配置を含める。

## 意味の保持

表現の意味 \(\llbracket e\rrbracket_\Gamma\subseteq\Gamma\) を、その表現と両立する状況の集合として与える。これは評価者が定める意味であり、読者の解釈とは区別する。

目的に必要な情報を取り出す写像を \(\pi_G:\Omega\to Z_G\) とする。\(Z_G\) は必要な条件・結果・理由の組み合わせの集合で、集合への適用は要素を写した集合を表す。

\[
\operatorname{Faithful}_G(e,C)
\iff
\llbracket e\rrbracket_\Gamma\ne\varnothing
\land
\pi_G(\llbracket e\rrbracket_\Gamma)=\pi_G(C)
\]

目的に必要な違いを、増やしも減らしもしない条件である。必要な条件の省略や、未説明のことの断定を防ぐ。すべての意味を保つ場合は \(\pi_G\) を恒等写像にする。

## 理解の条件

各課題 \(g\in G\) に対し、応答の集合 \(Y_g\) と、内容 \(C\) に照らして十分な応答の集合 \(B_g\subseteq Y_g\) を定める。状態 \(K\) での応答を \(a_K(g)\in Y_g\cup\{\bot\}\) とし、\(\bot\) は応答できないことを表す。

\[
\operatorname{Understands}_G(K,C)
\iff
\forall g\in G,\quad a_K(g)\in B_g
\]

課題には、説明の再生に加え、新しい事例の判断や反例の識別を含める。情報不足なら「判断できない」も十分な応答になり得る。判定は \(G\) の範囲に限る。

## 理解までの距離

読む、調べる、前に戻る、推論するなどの操作 \(o\in\mathcal O\) による状態遷移を、関係 \(K\xrightarrow{o}_{e,\mathcal E}K'\) で表す。同じ表現から理解にも誤解にも進み得る。

\(K_0\) から始まり、閲覧条件に従う有限の過程を \(\mathcal P(e,K_0,\mathcal E)\) とする。最終状態が理解の条件を満たす過程の集合を \(\mathcal P^+_G\) とする。

過程 \(p=(K_0,o_1,K_1,\ldots,o_n,K_n)\) の費用を次で定義する。

\[
\mathbf c(p)=
\left(
\sum_{i=1}^n t_i,\;
\sum_{i=1}^n u_i,\;
\sum_{i=1}^n b_i,\;
\sum_{i=1}^n s_i,\;
\max_{0\le i\le n}m(K_i)
\right)
\]

| 成分       | 負担                         |
| ---------- | ---------------------------- |
| \(t_i\)    | 操作時間                     |
| \(u_i\)    | 未知の語を調べること         |
| \(b_i\)    | 省略や誤解を補うこと         |
| \(s_i\)    | 情報を探すこと・往復すること |
| \(m(K_i)\) | 同時に保持する必要がある情報 |

各成分は非負とし、空の和は0とする。単位・測定方法・重み \(w_j>0\) を固定して、理解までの距離を定義する。

\[
d_w(e\mid K_0,C,G,\mathcal E)
=\inf_{p\in\mathcal P^+_G}w^\mathsf T\mathbf c(p)
\]

成功過程がなければ \(d_w=+\infty\) とする。これは費用の下限であり、対称性や三角不等式を仮定しない。また、読者が実際に最小費用の過程を選ぶとは限らない。

## 表現の比較

同じ評価の前提と費用の測り方のもとで、意味を保ち、理解までの距離が小さい表現を優先する。

\[
e_1\prec_w e_2
\iff
\operatorname{Faithful}_G(e_1,C)
\land\operatorname{Faithful}_G(e_2,C)
\land d_w(e_1)<d_w(e_2)
\]

重みを置かない場合は成功過程の費用ベクトルを比較し、全成分で大きくなく、一つ以上で小さい過程を優位とする。成分が競合する場合は優劣を決めない。

実際の理解のしやすさには、成功する経路の存在に加え、その経路を辿れる確率も関わる。制限時間 \(\tau\) 内の過程に、誤解や途中離脱も含めた確率分布 \(\mu_{e,K_0,\mathcal E,\tau}\) を与える場合、成功確率は次になる。

\[
q_\tau(e)=\mu_{e,K_0,\mathcal E,\tau}
\bigl(\{p\mid\operatorname{Understands}_G(K_{\mathrm{last}(p)},C)\}\bigr)
\]

距離による比較と成功確率は分けて評価する。

## 適用

具体的な評価には、意味の解釈、課題と十分な応答、読者の状態、操作と費用を与える。成功確率には過程の分布も必要になる。普遍的な重みや測定方法は定めない。

本モデルから導く条件付きの性質は[定理](./theorems.md)、表現の変換と選択は[最適化戦略](./strategies.md)で扱う。
